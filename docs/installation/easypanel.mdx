# Easypanel

[Easypanel](https://easypanel.io/) is a server control panel that can deploy autobrr with one click using its official template, without needing to manually run Docker commands.

1. Open your Easypanel dashboard and create (or open) a project
2. Click **+ Add Service** and choose **Templates**
3. Search for **autobrr** and select it
4. Click **Create** to deploy the service

Easypanel runs the official `ghcr.io/autobrr/autobrr` image for you and mounts a persistent volume for its config.

See the [official autobrr template on Easypanel](https://easypanel.io/templates/autobrr) for more details.
